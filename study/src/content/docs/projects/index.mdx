프로젝트 이름을 펼치면 **01부터 시작하는 단계별 실습**이 나옵니다. 한 프로젝트 안에서는 같은 폴더를 사용하세요. 각 단계에서 저장한 코드나 측정 파일을 다음 단계가 이어받습니다.

## 어떤 프로젝트부터 시작할까?

처음이면 로컬 AI 벤치마크부터 시작하세요. 메모리가 궁금하면 양자화, 긴 문서를 반복해 읽는 비용이 궁금하면 KV 캐시가 적합합니다. API 서버는 모의 응답으로 먼저 완성할 수 있습니다. Metal 커널에는 Apple Silicon 맥이, 실제 장비 간 분산 실험에는 서로 접속할 수 있는 맥 두 대가 필요합니다.

- [AI 모델 양자화 실험실](/projects/quantization/) · ★★★☆☆  
  모델 변환 스크립트와 정밀도별 품질·성능 비교표

- [개인용 AI 추론 클라우드](/projects/inference-cloud/) · ★★★☆☆  
  API 키 발급, 모델 선택, 대기열, 스트리밍, 사용량 기록을 갖춘 서버

- [KV Cache 최적화 엔진](/projects/kv-cache/) · ★★★★☆

- [여러 맥을 연결한 분산 AI 서버](/projects/distributed-macs/) · ★★★★★
