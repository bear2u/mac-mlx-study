두 질문이 공유하는 토큰열까지만 계산해 safetensors 파일로 저장합니다. 원본 접두부를 나중에 대조할 메타데이터도 함께 남깁니다.

## 왜 문자열 길이로 자르면 안 될까?

토크나이저는 줄바꿈이나 인접한 글자를 묶을 수 있습니다. 또 채팅 템플릿은 역할 구분 기호를 삽입합니다. 실제 질문 두 개에 템플릿을 적용한 뒤, 맨 앞에서부터 **토큰 ID가 완전히 일치하는 구간**을 찾습니다. 새 질문마다 이 구간이 일치하는지도 다시 확인합니다.

## 캐시 빌더 작성

`store.py`에 저장하세요. 파일 이름에는 모델의 고정 리비전, 엔진 버전과 공통 ID가 모두 반영됩니다. 모델·문서·시스템 지시가 바뀌었을 때 이전 상태를 잘못 고르는 일을 막을 수 있습니다. 같은 폴더를 여러 프로세스에서 읽더라도 완성된 임시 파일만 최종 이름으로 교체합니다.

```python
from hashlib import sha256
from importlib.metadata import version
from pathlib import Path
import json
from uuid import uuid4
import mlx.core as mx
from mlx_lm import load
from mlx_lm.models.cache import make_prompt_cache, save_prompt_cache
from common import inputs, spec

def prefix_for(tok, doc):
    left = inputs(tok, doc, "가")
    right = inputs(tok, doc, "Z")
    length = 0
    for a, b in zip(left, right):
        if a != b:
            break
        length += 1
    if length == 0:
        raise ValueError("공통 토큰이 없습니다")
    return left[:length]

def location(prefix):
    settings = [spec["repo"], spec["revision"], version("mlx-lm"), version("mlx"), prefix]
    key = sha256(json.dumps(settings).encode()).hexdigest()
    return Path("cache") / f"{key}.safetensors"

def build(model, prefix, path):
    state = make_prompt_cache(model)
    for start in range(0, len(prefix), 256):
        chunk = mx.array(prefix[start:start + 256])[None, :]
        model(chunk, cache=state)
        mx.eval([layer.state for layer in state])
    path.parent.mkdir(exist_ok=True)
    tmp = path.with_name(f".{uuid4().hex}.safetensors")
    try:
        save_prompt_cache(str(tmp), state, {"key":path.stem, "tokens":str(len(prefix))})
        tmp.replace(path)
    finally:
        tmp.unlink(missing_ok=True)

if __name__ == "__main__":
    model, tok = load(spec["path"])
    prefix = prefix_for(tok, Path("document.txt").read_text())
    path = location(prefix)
    build(model, prefix, path)
    print(len(prefix), "공통 토큰", path, path.stat().st_size, "bytes")
```

**확인** · `python store.py`를 실행해 캐시 파일 크기와 공통 토큰 수를 적습니다. 공통 구간 길이가 2단계의 전체 입력 길이보다 작은지 확인하세요. 256토큰씩 이어 붙일 때 앞 청크가 만든 캐시 객체를 다음 청크로 넘깁니다.

**막힐 때** · 확장자 오류가 나오면 임시 파일과 최종 파일이 모두 .safetensors로 끝나는지 확인합니다. 저장 공간이 부족하면 문서 길이를 줄여 새 기준과 캐시를 만드세요. [MLX-LM 캐시 저장 API](https://github.com/ml-explore/mlx-lm/blob/main/mlx_lm/models/cache.py)
