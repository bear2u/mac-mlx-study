문서 한 벌에 질문만 바꿔 보내는 환경을 만듭니다. 같은 모델과 토크나이저를 다시 불러올 수 있도록 버전을 고정합니다.

## 실험 폴더 만들기

Apple Silicon 맥에서 arm64 Python 3.11 이상을 사용하세요. 아래 명령은 양자화 프로젝트와 독립적으로 실행할 수 있습니다. 새 터미널에서는 cd와 source를 다시 실행합니다.

```sh
mkdir -p ~/mac-inference-lab/kv/{cache,results}
cd ~/mac-inference-lab/kv
python3 -m venv .venv
source .venv/bin/activate
python -m pip install mlx-lm huggingface_hub
python -m pip freeze > requirements-lock.txt
```

## 원본과 입력 고정하기

아래 내용을 `prepare.py`로 저장하고 `python prepare.py`를 실행하세요. 작은 모델로 캐시의 동작을 확인하고, 길이는 숫자 범위 하나로 조절합니다.

```python
import json
from pathlib import Path
from huggingface_hub import model_info, snapshot_download

repo = "mlx-community/Qwen2.5-0.5B-Instruct-4bit"
version = model_info(repo).sha
path = snapshot_download(repo, revision=version,
                         allow_patterns=["*.safetensors", "*.json", "*.txt", "*.model", "*.jinja"])
Path("model.json").write_text(json.dumps(dict(repo=repo, revision=version, path=path), indent=2))
lines = [f"{n}번 서랍에는 회색 종이가 있다." for n in range(1, 121)]
lines[0] = "1번 서랍에는 파란 종이가 있다."
Path("document.txt").write_text("\n".join(lines))
```

**확인** · `head -2 document.txt`에서 서로 다른 두 색을 확인하세요. “1번 서랍의 종이 색은?”과 “120번의 종이 색은?”이 이후 검증 질문입니다. 문서 파일을 변경한 뒤 prepare.py를 재실행하면 초기 문서가 다시 만들어집니다.

**막힐 때** · 다운로드가 멈추면 디스크 여유와 연결을 확인하세요. 이미 내려받은 모델의 경로와 revision이 model.json에 있으면 이후 단계에서 다운로드를 반복할 필요가 없습니다. [실습 모델 카드](https://huggingface.co/mlx-community/Qwen2.5-0.5B-Instruct-4bit)
