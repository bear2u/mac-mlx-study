먼저 GPU 없이 연결 경로를 검사합니다. 연습용 서버는 1초마다 한 조각씩 응답하고 마지막에 정해진 토큰 수를 보냅니다. 이 값은 뒤에서 저장 코드가 올바른지 확인할 시험 데이터입니다.

## fixture.py 저장하기

```python
import asyncio
import json
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.post("/v1/chat/completions")
async def chat():
    async def events():
        for word in ["실습", " 성공"]:
            await asyncio.sleep(1)
            chunk = {"choices": [{"delta": {"content": word}}]}
            yield f"data: {json.dumps(chunk, ensure_ascii=False)}\n\n"
        yield 'data: {"choices":[],"usage":{"prompt_tokens":8,"completion_tokens":2}}\n\n'
        yield "data: [DONE]\n\n"
    return StreamingResponse(events(), media_type="text/event-stream")
```

## 터미널 A에서 엔진 시작

```sh
python -m uvicorn fixture:app --host 127.0.0.1 --port 8091
```

## 터미널 B에서 응답 관찰

```sh
curl -NsS -X POST http://127.0.0.1:8091/v1/chat/completions   -H 'Content-Type: application/json' -d '{}'
```

약 2초 동안 두 개의 내용 이벤트, usage 이벤트, 마지막 `[DONE]`이 차례로 나옵니다. 빈 줄은 이벤트의 경계입니다. 브라우저로 주소를 열어 405가 나온 경우에는 위와 같이 POST 요청으로 검사하세요. 터미널 A를 켜 둡니다.
